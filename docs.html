01 / Overview

The cognitive memory model

Instead of relying only on cosine similarity over flat vectors, AI Brain links concepts, execution histories and agent intentions into a single persistent hypergraph — so recall can follow relationships, not just keywords.

Engine

Cognitive hypergraph

Multi-hop associative reasoning with temporal decay protection.

Coordination

Swarm consensus

Shared memory state synchronised across many concurrent agents.

03 / Core SDK

Hypergraph memory API

Store long-term agent experiences with remember() and retrieve them with multi-hop recall().

memory.py — API previewpreview
import aibrain

# 1. Initialise the hypergraph client
brain = aibrain.HypergraphClient(
    api_key="sk_live_...",
    tier="ENTERPRISE",
)

# 2. Ingest cross-session memory
memory_node = brain.remember(
    agent_id="executive_agent_01",
    context={
        "user_intent": "Deploy agent swarm",
        "tech_stack": ["Google Cloud", "Gemini"],
        "rule": "Zero context decay across sessions",
    },
    reasoning_weight=0.98,
    decay_protection=True,
)

# 3. Multi-hop associative recall
graph_result = brain.recall(
    agent_id="executive_agent_01",
    query="What architecture rules were specified?",
    depth=4,  # 4-hop graph traversal
    top_k=5,
)

print("Recall latency:", graph_result.latency_ms, "ms")
print("Retrieved nodes:", graph_result.nodes)
04 / Multi-agent

Swarm consensus protocol

Synchronise state across concurrent agents — planner, coder, reviewer — without collisions or context drift.

swarm.py — API previewpreview
import aibrain

# 1. Connect an agent swarm
swarm = aibrain.SwarmGrid(
    swarm_id="swarm_alpha_dev",
    agents=["planner_agent", "coder_agent", "evaluator_agent"],
    consensus_protocol="BYZANTINE_HYPERGRAPH_AGREEMENT",
)

# 2. Broadcast a verified artifact to every agent
swarm.broadcast_state(
    source_agent="coder_agent",
    state_key="verified_memory_spec",
    payload={"status": "PASSED_TESTS", "code_coverage": "99.8%"},
    consensus_mode="IMMEDIATE_SYNC",
)

# 3. Read synchronised state
current_state = swarm.read_state(
    agent_id="evaluator_agent",
    state_key="verified_memory_spec",
)
print("Swarm sync status:", current_state.status)
05 / HTTP

REST API reference

Planned endpoints for Go, Rust, Java, C++ or anything that speaks HTTP. Not live yet.

POST/v1/memory/remember

Ingest and index new context into the hypergraph.

POST/v1/memory/recall

Run a multi-hop traversal and return relevant context for an agent.

POST/v1/swarm/sync

Broadcast a state update to every agent in a swarm.
