Infrastructure as code

Reference deployment.

A starting sketch for a self-hosted AI Brain cluster on Google Cloud (not a turnkey installer). Enterprise customers will get a tailored blueprint.

Ask about self-hosting →

deploy_cluster.sh — reference sketchGCP
# Reference sketch: GKE cluster + TPU v5e node pool.
# Check TPU quota and zone availability for your project before running.
gcloud container clusters create "aibrain-mesh" \
  --region="us-central1" \
  --release-channel=regular \
  --workload-pool="PROJECT_ID.svc.id.goog" \
  --enable-shielded-nodes

gcloud container node-pools create "tpu-v5e" \
  --cluster="aibrain-mesh" --region="us-central1" \
  --node-locations="us-central1-a" \
  --machine-type="ct5lp-hightpu-4t" --tpu-topology="2x2" \
  --num-nodes=1 --enable-autoscaling --min-nodes=0 --max-nodes=4
