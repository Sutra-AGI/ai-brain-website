चार तरह की मेमोरी, एक ग्राफ़।

क्या हुआ, उसका मतलब क्या था, और सब कुछ आपस में कैसे जुड़ा है — सब एक जगह।

01

बातचीत की मेमोरी

हर सेशन, हर यूज़र और हर डिवाइस पर पूरा संदर्भ — बिना दोबारा प्रॉम्प्ट किए।

02

नॉलेज ग्राफ़

लोग, प्रोजेक्ट और फ़ैसले आपस में जुड़े रहते हैं, ताकि जुड़ा हुआ संदर्भ भी मिल सके।

03

आइडिया मेमोरी

कच्चे विचारों को अपने-आप व्यवस्थित, जुड़े हुए नोट्स में बदलती है।

04

प्रोजेक्ट मेमोरी

प्रोजेक्ट की स्थिति, कोड का इतिहास और माइलस्टोन रियल टाइम में।

कैसे काम करता है

प्रॉम्प्ट से स्थायी मेमोरी तक।

Google Cloud पर बना पाइपलाइन — किनारे पर सर्वरलेस, बीच में ग्राफ़।

01 — CLIENT

SDK (जल्द आ रहा है)

Python और TypeScript SDK।

02 — COMPUTE

Cloud Run गेटवे

ज़रूरत के हिसाब से बढ़ने-घटने वाली API लेयर।

03 — COGNITION

Vertex AI

संदर्भ समझना और embeddings बनाना।

04 — PERSISTENCE

हाइपरग्राफ़ स्टोर

मेमोरी को सुरक्षित रूप से सहेजना।

एजेंट नेटवर्क

पाँच विशेषज्ञ एजेंट्स, एक साझा ग्राफ़।

हर एजेंट एक ही स्थायी नॉलेज ग्राफ़ से जुड़ा रहता है, इसलिए पिछला संदर्भ व निर्णय स्वचालित रूप से आगे बढ़ते हैं।

01

Research Agent

दस्तावेज़ों की खोज, साइटेशन मिलान और बहु-स्रोत कार्यकारी रिपोर्ट तैयार करना।

02

Coding Agent

पूरे कोडबेस और पिछले कमिट इतिहास की याद के साथ रीफ़ैक्टरिंग व यूनिट टेस्ट।

03

Strategy & Knowledge Agent

परिदृश्य विश्लेषण, OKR ड्राफ़्टिंग, एंटिटी लिंकिंग और वास्तविक समय सिमैंटिक इंडेक्सिंग।

04

Automation Agent

वेबहुक्स, CI/CD पाइपलाइन और 24/7 सेल्फ-हीलिंग क्लाउड निगरानी।

# प्री-रिलीज़ API प्रीव्यू (पैकेज अभी प्रकाशित नहीं)
import aibrainstartup

client = aibrainstartup.Client(api_key="sk_live_...")
ctx = client.memory.recall(user_id="usr_42", query="current sprint")

res = client.agents.run(
    agent="coding",
    prompt="Fix the flaky test",
    context=ctx,
)
print(res.output)

AI Brain क्या है?

AI Brain एक शुरुआती चरण का भारतीय स्टार्टअप है जो LLM और AI एजेंट्स के लिए स्थायी, आपस में जुड़ी मेमोरी लेयर बना रहा है। प्रोडक्ट अभी विकास में है — अर्ली एक्सेस के लिए वेटलिस्ट से जुड़ें।

स्थायी मेमोरी कैसे काम करेगी?

यह vector embeddings और नॉलेज ग्राफ़ को मिलाकर बातचीत, आइडिया और प्रोजेक्ट के संदर्भ को जुड़े हुए नोड्स के रूप में सहेजेगी, ताकि अगले सेशन में भी वह याद रहे।

क्या SDK अभी उपलब्ध है?

नहीं, SDK जल्द आ रहा है। PyPI या npm पर मिलते-जुलते नाम वाले पैकेज (जैसे aibrain) हमारे नहीं हैं — उन्हें इंस्टॉल न करें।
