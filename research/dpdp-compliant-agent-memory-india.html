India & Governance

Building DPDP-Compliant Agent Memory in India

Architectural patterns for strict tenant isolation, purpose limitation, and deterministic memory erasure under India’s Digital Personal Data Protection Act, 2023.

Published 2026-11-267 min readBy Bhoja Ram Choudhary

1. Why Vector Stores Struggle with Right-to-Erasure

Under India’s DPDP Act, 2023 (Section 12 — Right to correction and erasure of personal data), Data Principals can withdraw consent and demand verifiable deletion of their personal context. Append-only RAG stores face serious operational friction:

  • A single conversation chunk often entangles multiple entities and shared system summaries.
  • Rebuilding HNSW vector indexes after sparse metadata deletion causes write amplification or temporarily leaked stale vectors in replicas.

2. Tenant-Partitioned Memory Graphs + Deterministic Tombstones

AI Brain’s planned architecture models privacy as a first-class graph boundary rather than an afterthought:

  1. Cryptographic Tenant Namespaces: Per-tenant envelope keys managed with Cloud KMS (AES-256 at rest) and TLS 1.3 in transit inside VPC Service Controls boundaries.
  2. Scoped Node Ownership: Every episodic memory node carries explicit tenant_id and subject_id ownership so deletion cascades deterministically along owned hyperedges.
  3. Regional Residency Enforcement: Separating stateless compute gateways from regional graph storage planes (asia-south1 Mumbai / Delhi) for regulated Indian fintech and enterprise deployments.
