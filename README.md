# AI Brain — website

Source for **[aibrainstartup.com](https://aibrainstartup.com)**, the marketing site of AI Brain — an early-stage startup building a persistent, associative memory layer for LLMs and autonomous AI agents.

> The AI Brain SDK and API are **not published yet**. Packages on PyPI or npm named `aibrain`, `aibrain-sdk` or `@aibrain/sdk` are not affiliated with this project.

## Stack

- Static HTML/CSS/JS, no framework or build step for the pages
- Two Vercel Functions (`api/`) that store form submissions in a private Vercel Blob store
- Hosted on Vercel (`vercel.json` holds security headers and caching); every push to `main` deploys to production automatically

```
index.html                 homepage (hand-written)
about|architecture|docs|contact|privacy-policy|terms-of-service|404.html
                           generated by scripts/build_pages.py
home.css, pages.css        design system (shared / sub-page components)
home.js                    all client-side behaviour
fonts/                     self-hosted Geist, Geist Mono, Instrument Serif (SIL OFL)
icons/, og.jpg, favicon.ico
api/waitlist.js            POST /api/waitlist  → Blob: waitlist/<hash>.json
api/contact.js             POST /api/contact   → Blob: contact/<date>/<id>.json
api/_lib.js                origin check, bot checks, rate limiting, Blob helpers
```

## Local development

```bash
npm install
npx vercel dev        # serves pages + /api with clean URLs
```

`python3 -m http.server` also works for the static pages (use `/about.html` style URLs; the API will not run).

## Editing pages

- **Homepage:** edit `index.html` directly.
- **Sub-pages:** edit the templates in `scripts/build_pages.py`, then run:

```bash
python3 scripts/build_pages.py
```

The script keeps each page's SEO `<head>`, regenerates nav/body/footer, and refreshes the `?v=` cache-busting hash on every page. **Run it after any change to `home.css`, `pages.css` or `home.js`** — those files are served with a one-year immutable cache.

## Form data

Signups and contact messages are stored privately in the Vercel Blob store **aibrain-waitlist**
(Vercel dashboard → Storage → aibrain-waitlist). The `BLOB_READ_WRITE_TOKEN` environment variable is set automatically by Vercel.
